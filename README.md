# GAME ARCADE — Vercel-ready

Import this folder into Vercel as a static site. No build command is required; output directory is `.`.

## Included
- Local supplied logo asset
- Image-first product cards with lazy loading
- Responsive 3D/neon arcade UI
- Functional cart with localStorage
- Admin dashboard demo
- Vercel cache/security headers

## Production note
The product cards currently reference demo remote image URLs from third-party listings. Replace these with store-owned/licensed images under `public/assets/` before commercial launch.

Checkout, authentication, inventory, orders, and admin persistence are still front-end demo hooks and should be connected to a real backend/payment provider for production.
